# aframe-whack-a-mole

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

A VR whack-a-mole game.

## Demo
You can [try out the game by following this link](https://acodedoer.github.io/aframe-whack-a-mole/)

## Features
- Simple virtual-reality whack-a-mole game
- Uses a cursor for interaction, no controllers required
- Configurable game duration and difficulty

## Usage

### Install and Run
1. Clone the repo
   ```sh
   git clone https://github.com/acodedoer/aframe-whack-a-mole.git
   ```
2. Configure the game
   You can set the duration of the game using the `gameDuration` property of the `control` component (a "short" game lasts 30 seconds, while "long" game lasts 45 seconds). You can also adjust the game difficulty using the `popMultiple` property of the `control` component (true displays multiple moles at a time while false displays a single mole at a time).
